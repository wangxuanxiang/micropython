# IMU660RX execution plan (user approved)

Implement all nine requested items in place, preserving Windows source then
syncing only task files into the user's WSL checkout. No flashing in this task.

1. Replace incomplete modseekfree draft with checked, rooted C bindings;
   capture_div for capture, immediate read, stable live six-int list for get.
2. imu_port.c: chip detection, full RA configuration upload, RB/RC register
   setup, SPI2/4 bounded register transport with no HAL DMA in timer IRQ.
3. Protect SPI and GPIO ownership; release on failed init/deinit/soft reset.
4. ticker stores mp_obj_t sensors and dispatches only recognized native types;
   validate full replacement before detach/attach. Preserve ADC/encoder tests.
5. Unix injected register model verifies signed decoding, initialization errors,
   divided sampling, live data, failure recovery, GC and mixed ticker capture.
6. Rebuild Unix and ARM, inspect symbols, export new firmware to separate
   artifacts/seekfree-WEACTSTUDIO_MINI_STM32H743 with checksums and test results.
7. Adapt E24 board demo and document supported chips/wiring/timing limitations.

Rulings: get returns the same list as required by E24; do not resize it. read
forces sampling without consuming capture division count. One IMU object at
a time, SPI2 default; SPI4 optional and cannot share board LCD. GPIO pin choice
follows hardware bus mapping, custom CS is supported. Hardware test remains
separate from Unix model and cross-compilation.
